# Sistema de disseny

Extret d'aracaldes.cat (WordPress + tema Hestia) el 20/11/2026. Valors aplicats a `src/app/globals.css`.

- Capçalera fotogràfica de Caldes amb overlay negre al 50 % i panell blanc que hi puja per sobre (-60 px), radi de 6 px i ombra gran.
- Tipografia: Roboto (text, 16 px / 400) i Roboto Slab 700 (títols).
- Colors: text #3C4858, fons #E5E5E5, peu #323437. Accent: corall del logo #E85858 per a elements decoratius, i #C94444 per als botons amb text blanc (contrast 4,8:1, AA).
- El morat (#89229B) i el blau (#23527C) de la web actual són els que porta el tema per defecte i no es fan servir.
- Sense gradients ni animacions vistoses. Focus visible a tots els elements interactius.
